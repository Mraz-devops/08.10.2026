# Мои команды Linux
## Навигация
- pwd — показать, где я сейчас
- ls — показать, что вокруг
- cd папка — перейти в папку
- cd .. — вернуться на уровень выше
- cp файл1 файл2 — копировать
- mv файл1 файл2 — переместить/переименовать
- rm файл — удалить файл
- grep "текст" файл        # найти текст в файле
- ps aux                   # список процессов
- top                      # процессы в реальном времени
- chmod 755 файл           # дать права на выполнение
- chown user:group файл    # сменить владельца
## Права и диски
- chmod 755 файл — rwx для владельца, r-x для остальных
- chmod +x файл — добавить право на выполнение
- chown user:group файл — сменить владельца
- df -h — свободное место на дисках
- du -sh папка — сколько занимает папка
