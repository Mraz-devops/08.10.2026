# Мои команды Linux
## Навигация
- pwd — показать, где я сейчас
- ls — показать, что вокруг
- cd папка — перейти в папку
- cd .. — вернуться на уровень выше
- cp файл1 файл2 — копировать
- mv файл1 файл2 — переместить/переименовать
- rm файл — удалить файл
- grep "текст" файл        # найти текст в файле
- ps aux                   # список процессов
- top                      # процессы в реальном времени
## Права и диски
- chmod 755 файл — rwx для владельца, r-x для остальных
- chmod +x файл — добавить право на выполнение
- chown user:group файл — сменить владельца
- df -h — свободное место на дисках
- du -sh папка — сколько занимает папка
## Архивы и поиск
- tar -czf архив.tar.gz папка — создать архив
- tar -xzf архив.tar.gz — распаковать
- tar -tzf архив.tar.gz — посмотреть содержимое
- find . -name "*.txt" — найти файлы по имени
- find . -type d — только папки
- find . -type f — только файлы
- history — история команд
- history | grep git — найти команды с git
## Сеть и удалённые серверы
- ssh user@host — подключиться к серверу
- ssh user@host -p 2222 — подключиться на порт 2222
- scp file.txt user@host:/path/ — скопировать файл на сервер
- scp -r папка/ user@host:/path/ — скопировать папку
- scp user@host:/path/file.txt . — скачать файл с сервера
- wget URL — скачать файл из интернета
- wget -O имя URL — скачать с новым именем
- wget -c URL — продолжить прерванную загрузку
- curl URL — получить данные по URL
